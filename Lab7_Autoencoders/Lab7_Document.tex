\section*{1. Objective}

The objective of this experiment is to develop an end-to-end understanding of
autoencoders and their variants for image representation, reconstruction,
denoising and generative modeling.

The experiment begins with a fully connected autoencoder, progresses to a
Convolutional Autoencoder (CAE), introduces image corruption for denoising,
and finally develops a Variational Autoencoder (VAE). Students will visualize
the learned latent representation, compare reconstruction quality using
quantitative and qualitative measures, and explore the generative capability
of the VAE.

The same image dataset and a controlled experimental protocol should be used
throughout the experiment wherever possible.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section*{2. Learning Outcomes}

After completing this experiment, students will be able to:

\begin{itemize}
\item explain the encoder--latent--decoder structure of an autoencoder;
\item prepare image data for reconstruction-based learning;
\item implement a fully connected autoencoder;
\item implement a Convolutional Autoencoder for image reconstruction;
\item introduce controlled noise and build a denoising autoencoder;
\item evaluate reconstruction using MSE, MAE and SSIM;
\item visualize and interpret latent representations;
\item explain the probabilistic latent representation of a VAE;
\item implement the reparameterization trick;
\item calculate and interpret reconstruction and KL-divergence losses;
\item generate new images by sampling from a learned latent space; and
\item compare deterministic and variational latent representations.
\end{itemize}

\section*{3. Dataset and Experimental Setup}

\textbf{Dataset: MNIST Handwritten Digit Dataset}

MNIST contains grayscale images of handwritten digits from 0 to 9. Each image
has spatial dimensions

\[
28\times28\times1.
\]

The dataset is particularly suitable for this experiment because the images
are small, the classes have visually meaningful structure, and the same image
format can be directly supplied to fully connected, convolutional and
variational autoencoders.

The dataset can be loaded directly using Keras/TensorFlow:

\url{https://www.tensorflow.org/api_docs/python/tf/keras/datasets/mnist}

\textbf{Recommended laboratory subset:}

Use 10,000 training images and 2,000 test images for the main laboratory
execution. The full MNIST dataset may be used if computational resources
permit.

The labels are not required as reconstruction targets. The original image is
the target:

\[
\boxed{x\rightarrow \text{Encoder}\rightarrow z
\rightarrow\text{Decoder}\rightarrow\hat{x}}
\]

where $x$ is the input image and $\hat{x}$ is its reconstruction.

\section*{6. Exploring Autoencoders}

An autoencoder learns to reproduce its input at the output.

The encoder maps the input to a lower-dimensional representation:

\[
z=f_{\theta}(x),
\]

and the decoder reconstructs the input:

\[
\hat{x}=g_{\phi}(z).
\]

The training objective is to minimize reconstruction error:

\[
\mathcal{L}_{rec}
=
\frac{1}{N}\sum_{i=1}^{N}
\|x_i-\hat{x}_i\|^2.
\]

\begin{tikzpicture}[node distance=7mm]

\node[layer,right=of a](b){Encoder};
\node[layer,right=of b](c){Latent\\Vector $z$};
\node[layer,right=of c](d){Decoder};
\node[layer,right=of d](e){Output Image\\$\hat{x}$};

\foreach \x/\y in {a/b,b/c,c/d,d/e}
\draw[arrow](\x)--(\y);
\end{tikzpicture}
\end{center}

The latent vector is a compressed representation of the input.

\section*{15. Variational Autoencoder}

A conventional autoencoder maps an input to a deterministic latent vector:

\[
z=f(x).
\]

A VAE instead learns a probability distribution:

\[
q_{\phi}(z|x)
=
\mathcal{N}
\left(
\mu(x),
\operatorname{diag}(\sigma^2(x))
\right).
\]

The encoder produces:

\[
\mu,\qquad \log\sigma^2.
\]

A latent vector is sampled using the reparameterization trick:

\[
z=\mu+\sigma\odot\epsilon,
\qquad
\epsilon\sim\mathcal{N}(0,I).
\]

\begin{center}
\begin{tikzpicture}[node distance=6mm]
\node[layer](a){Input Image};
\node[layer,right=of a](b){Encoder};
\node[layer,right=of b](c){$\mu,\log\sigma^2$};
\node[layer,right=of c](d){Sampling\\$z=\mu+\sigma\epsilon$};
\node[layer,right=of d](e){Decoder};
\node[layer,right=of e](f){Reconstructed\\Image};

\foreach \x/\y in {a/b,b/c,c/d,d/e,e/f}
\draw[arrow](\x)--(\y);
\end{tikzpicture}
\end{center}

\section*{16. VAE Loss Function}

The VAE objective consists of two components.

\subsection*{Reconstruction Loss}

\[
\mathcal{L}_{rec}
=
-\mathbb{E}_{q_{\phi}(z|x)}
[\log p_{\theta}(x|z)].
\]

For normalized MNIST images, binary cross-entropy can be used.

\subsection*{KL Divergence}

\[
D_{KL}
\left(
q_{\phi}(z|x)\parallel p(z)
\right)
=
-\frac{1}{2}
\sum_j
\left(
1+\log\sigma_j^2-\mu_j^2-\sigma_j^2
\right).
\]

The total loss is

\[
\boxed{
\mathcal{L}_{VAE}
=
\mathcal{L}_{rec}
+
\mathcal{L}_{KL}
}
\]

where the prior is usually

\[
p(z)=\mathcal{N}(0,I).
\]

\subsection*{Plot 1: Original versus Reconstructed Images (Basic FC Autoencoder)}

\begin{figure}[H]
\centering
\includegraphics[width=0.88\linewidth]{Images/fc_ae_reconstruction.png}
\caption{Reconstruction results of the Fully Connected Autoencoder ($d_z = 16$). Top row: Original MNIST test digits. Bottom row: Corresponding decoded reconstructions $\hat{x}$.}
\end{figure}

\textbf{Inference:} The plot compares original MNIST test digits with reconstructions from the Fully Connected Autoencoder ($d_z = 16$). The reconstructed outputs correctly capture digit class identity and orientation, but exhibit visible blurring and softened stroke edges, reflected in a moderate $\text{SSIM} = 0.728950$ and $\text{MSE} = 0.022779$. Flattening 2D images to 1D discards spatial locality, forcing fully connected layers to learn pixel correlations globally, which promotes low-pass smoothing under MSE loss. This confirms that while a fully connected AE learns meaningful compressed representations, it lacks the spatial inductive bias needed for sharp, high-fidelity reconstruction.

\begin{figure}[H]

\textbf{Inference:} The plot shows training and validation Binary Cross-Entropy loss over 20 epochs for the Fully Connected Autoencoder. Both curves drop steeply in the first 4 epochs then gradually plateau near $0.095$, with training and validation loss remaining tightly coupled throughout, indicating no overfitting. The bottleneck dimension ($d_z = 16$) acts as an implicit regularizer, preventing the $211,040$ parameters from memorizing individual samples. The smooth convergence confirms that the Adam optimizer and the chosen architecture are well-suited for stable reconstruction learning on the MNIST subset.

\section*{28. Discussion Questions}

\begin{enumerate}
\item \textbf{What is an autoencoder?}\\[1.5mm]
\textbf{Answer:} An autoencoder is an unsupervised neural network. It consists of encoder, bottleneck and decoder . The encoder compresses the input into a latent bottleneck and a decoder  reconstructs the input. The network is trained by minimizing reconstruction error between the original input and reconstructed output. The bottleneck makes sure the network learns dominant hidden patterns rather than memorizing individual samples.

\vspace{5mm}

\item \textbf{What is the purpose of the encoder?}\\[1.5mm]
\textbf{Answer:} The encoder acts as a dimensionality reduction and feature extraction function, denoted as $z = f_\theta(x)$. Its purpose is to map high-dimensional raw input data (e.g., pixel arrays) into a compact latent vector space. It progressively discards redundant information, noise, and irrelevant variations while preserving essential semantic features. This compressed code captures the underlying coordinates of the data manifold required for faithful reconstruction.

\vspace{5mm}

\item \textbf{What is the purpose of the decoder?}\\[1.5mm]
\textbf{Answer:} The decoder acts as a generative reconstruction network, denoted as $\hat{x} = g_\phi(z)$. Its primary purpose is to take the low-dimensional latent code from the encoder and reconstruct the original input in high-dimensional space. By inverting the bottleneck compression, it synthesizes an approximation of the input using learned structural priors. The decoder ensures that the latent space retains sufficient information fidelity to reconstruct identifiable, high-quality images.

\vspace{5mm}

\item \textbf{What is a latent representation?}\\[1.5mm]
\textbf{Answer:} A latent representation (or latent code) is an internal, compressed intermediate vector residing at the bottleneck layer between the encoder and decoder. It represents the data using hidden, unobserved variables that capture the intrinsic coordinates of the underlying data manifold. Rather than storing individual raw pixel values, it encodes high-level features such as stroke thickness, digit identity, angle, and curvature. This lower-dimensional representation facilitates data compression, clustering, and downstream transfer tasks.

\vspace{5mm}

\item \textbf{Why is the latent representation usually smaller than the input?}\\[1.5mm]
\textbf{Answer:} Constraining the latent dimension to be smaller than the input creates an undercomplete information bottleneck. This architectural constraint prevents the network from simply learning an identity or copy function that trivially memorizes inputs. By forcing compression, the network is compelled to discover compact statistical regularities, correlations, and essential structures. Consequently, it discards noise and retains only the most critical attributes necessary for faithful reconstruction.

\vspace{5mm}

\item \textbf{What happens when the latent dimension is too small?}\\[1.5mm]
\textbf{Answer:} When the latent dimension is excessively restricted (e.g., $d_z = 2$ for complex high-dimensional datasets), an information bottleneck occurs. The network lacks sufficient expressive capacity to store fine-grained structural and high-frequency details. This leads to high reconstruction loss (MSE), loss of fine stroke boundaries, and severe blurriness in the output images. Furthermore, distinct classes or features can overlap or collapse together in latent space, degrading reconstruction fidelity.

\vspace{5mm}

\item \textbf{What happens when the latent dimension is increased?}\\[1.5mm]
\textbf{Answer:} Increasing the latent dimension expands the capacity of the bottleneck, enabling the network to capture subtle nuances, sharp edges, and high-frequency textures. This monotonically reduces reconstruction error and increases perceptual metrics like SSIM. However, if the latent dimension is made excessively large, the network risks overfitting and learning trivial identity mappings. Overly high dimensionality can also diminish the quality of compression and make latent space clustering or visualization less meaningful.

\vspace{5mm}

\item \textbf{Why can a convolutional autoencoder preserve spatial information more effectively?}\\[1.5mm]
\textbf{Answer:} Convolutional autoencoders (CAEs) preserve spatial information by utilizing local receptive fields, shared weights, and 2D feature maps rather than flattening images into 1D vectors. Flattening in fully connected networks destroys the 2D geometric grid topology, spatial adjacency, and local pixel correlations. CAEs inherently possess translation equivariance, allowing them to detect local visual primitives (edges, curves, loops) regardless of their spatial location. This structural inductive bias results in sharper reconstructions with significantly fewer trainable parameters.

\vspace{5mm}

\item \textbf{Differentiate an autoencoder and a denoising autoencoder.}\\[1.5mm]
\textbf{Answer:} A standard autoencoder takes clean data $x$ as both input and target, learning to reconstruct the original input via an undercomplete bottleneck. A denoising autoencoder (DAE) receives a corrupted or noisy version $\tilde{x} = x + \eta$ at its input, while still using the original clean image $x$ as its reconstruction target. While a standard autoencoder primarily performs dimensionality reduction, a DAE learns vector fields that project off-manifold corrupted points back onto the true data manifold. This forces the DAE to learn robust, noise-invariant representations of data structure.

\vspace{5mm}

\item \textbf{Why is the clean image used as the target in denoising?}\\[1.5mm]
\textbf{Answer:} Using the clean image as the target forces the network to learn the underlying manifold of valid, noise-free data rather than reconstructing the corrupting noise. The optimization objective penalizes any residual noise present in the reconstruction, incentivizing the network to extract invariant underlying features. This teaches the model an orthogonal projection from noisy ambient space back to the high-density data manifold. Consequently, the network learns to filter out stochastic perturbations while preserving authentic structural contours.

\vspace{5mm}

\item \textbf{What happens when the noise level is increased?}\\[1.5mm]
\textbf{Answer:} As the input noise variance or standard deviation ($\sigma$) increases, the corrupted data points are pushed further away from the clean data manifold. At moderate noise levels, the autoencoder remains robust and effectively removes noise, albeit with slight loss in fine edge sharpness. However, at excessive noise levels, critical structural features and stroke topologies are masked or destroyed. This leads to a steep decline in SSIM, an increase in reconstruction MSE, and blurry or hallucinated reconstructions due to information loss.

\vspace{5mm}

\item \textbf{Why are MSE, MAE and SSIM useful for image reconstruction?}\\[1.5mm]
\textbf{Answer:} MSE (Mean Squared Error) and MAE (Mean Absolute Error) provide objective, pixel-by-pixel numeric measures of reconstruction residual intensity, where MSE penalizes large errors quadratically. However, pixel-wise metrics often fail to capture human perceptual visual quality and can favor uniformly blurred images. SSIM (Structural Similarity Index Measure) addresses this limitation by evaluating degradation of luminance, contrast, and structural inter-pixel dependencies. Combining these metrics provides a balanced evaluation of both numerical pixel accuracy and perceived visual fidelity.

\vspace{5mm}

\item \textbf{What is a Variational Autoencoder?}\\[1.5mm]
\textbf{Answer:} A Variational Autoencoder (VAE) is a directed probabilistic generative model that combines deep neural networks with variational Bayesian inference. Unlike deterministic autoencoders, the encoder maps each input to the parameters of a probability distribution (mean $\mu$ and log-variance $\log\sigma^2$) over the latent space. The decoder then samples latent vectors from this distribution to reconstruct the input. By training with an objective that balances reconstruction fidelity and latent regularization, VAEs ensure a continuous, smooth latent space suitable for generative sampling.

\vspace{5mm}

\item \textbf{How does a VAE differ from a conventional autoencoder?}\\[1.5mm]
\textbf{Answer:} A conventional autoencoder deterministically maps an input image to an isolated point in latent space, often resulting in gaps, discontinuities, and overfitting. In contrast, a VAE maps inputs to continuous probability density distributions, regularizing the latent space via Kullback-Leibler (KL) divergence against a standard normal prior. This constraint ensures that the latent space is smooth, complete, and devoid of empty ``holes''. Consequently, while conventional autoencoders are limited to reconstruction and compression, VAEs can generate novel, plausible samples by sampling from the prior distribution.

\vspace{5mm}

\item \textbf{Why does a VAE learn a distribution instead of a single latent vector?}\\[1.5mm]
\textbf{Answer:} Learning a distribution introduces controlled stochasticity and continuity into the latent space, preventing the encoder from encoding inputs as isolated, memorized points. By mapping inputs to regions defined by $\mu$ and $\sigma$, neighboring regions in the latent space correspond to semantically similar outputs. This prevents severe discontinuities and ``holes'' where the decoder would output nonsensical artifacts. The distributional formulation also provides a mathematically principled framework for sampling new data points from known prior distributions.

\vspace{5mm}

\item \textbf{What is the reparameterization trick?}\\[1.5mm]
\textbf{Answer:} The reparameterization trick is an algorithmic reformulation that enables gradient backpropagation through stochastic sampling nodes in a neural network. Direct random sampling $z \sim \mathcal{N}(\mu, \sigma^2)$ is non-differentiable because random variables lack continuous gradients with respect to network parameters. The trick isolates stochasticity by sampling an independent auxiliary noise vector $\epsilon \sim \mathcal{N}(0, I)$ and computing the latent vector deterministically as $z = \mu + \sigma \odot \epsilon$. This allows gradients of the loss function to flow directly through $\mu$ and $\sigma$ using standard backpropagation.

\vspace{5mm}

\item \textbf{Why is $\epsilon$ sampled from a standard normal distribution?}\\[1.5mm]
\textbf{Answer:} Sampling $\epsilon$ from a standard normal distribution $\mathcal{N}(0, I)$ provides a zero-mean, unit-variance parameter-free stochastic source that is completely independent of the model's weights. This independence ensures that the random generator does not participate in gradient calculation during backpropagation. Additionally, scaling and shifting a standard normal variable by $\sigma$ and $\mu$ mathematically generates the target Gaussian distribution $\mathcal{N}(\mu, \sigma^2)$ exactly. It also aligns directly with the standard Gaussian prior commonly enforced by the KL-divergence term.

\vspace{5mm}

\item \textbf{What is the role of KL divergence in the VAE loss?}\\[1.5mm]
\textbf{Answer:} The Kullback-Leibler (KL) divergence acts as a statistical regularizer that measures how much the encoder's posterior distribution $q_\phi(z|x)$ deviates from the prior $p(z) = \mathcal{N}(0, I)$. It penalizes distributions with means far from zero or variances diverging from unity, preventing the encoder from clustering classes into isolated, distant regions. This ensures that the latent space remains smooth, centered, and compactly packed without empty voids. Balancing the KL loss with reconstruction loss creates a trade-off between generative smoothness and sample reconstruction sharpness.

\vspace{5mm}

\item \textbf{What is the prior distribution used in the VAE?}\\[1.5mm]
\textbf{Answer:} The standard prior distribution used in a VAE is an isotropic multivariate Gaussian, defined as $p(z) = \mathcal{N}(0, I)$. This prior assumes that latent variables are zero-mean, mutually independent, and have unit variance across all dimensions. It provides a simple, continuous, and analytically tractable reference distribution for computing closed-form KL divergence with Gaussian posteriors. Furthermore, its standard normal form makes generating new samples straightforward by directly sampling random vectors from standard normal noise.

\vspace{5mm}

\item \textbf{Why is a two-dimensional latent space useful for visualization?}\\[1.5mm]
\textbf{Answer:} A two-dimensional latent space ($d_z = 2$) allows direct, unprojected Cartesian plotting of latent coordinates without requiring post-hoc dimensionality reduction techniques like PCA or t-SNE. It enables complete visualization of class clustering, class separation boundaries, and manifold topology on a single 2D plane. Researchers can also construct systematic 2D grid scans across coordinate intervals to inspect how digit shapes continuously transform across latent axes. This provides an intuitive, visually interpretable diagnostic tool for assessing latent space organization and smoothness.

\vspace{5mm}

\item \textbf{What does latent-space interpolation demonstrate?}\\[1.5mm]
\textbf{Answer:} Latent-space interpolation involves moving along a continuous trajectory (such as a straight line $z(\alpha) = (1-\alpha)z_A + \alpha z_B$) between two latent vectors and decoding intermediate points. It demonstrates whether the learned latent space is continuous, compact, and semantically well-ordered. If the decoded images morph smoothly from one digit class to another without producing garbled artifacts, it proves the manifold lacks holes or voids. This confirms that the decoder has learned a meaningful underlying generative representation of the data distribution.

\vspace{5mm}

\item \textbf{Why can a VAE generate new images?}\\[1.5mm]
\textbf{Answer:} A VAE can generate new images because its training objective regularizes the encoder distribution to approximate a known, tractable prior $p(z) = \mathcal{N}(0, I)$. Because the latent space is continuous and dense, almost any latent vector sampled from this prior maps to a valid point on the data manifold. To synthesize a novel image, one simply draws a random sample $z \sim \mathcal{N}(0, I)$ and passes it through the trained decoder. The decoder then reconstructs a realistic synthetic image possessing the characteristic features of the training domain.

\vspace{5mm}

\item \textbf{Why might some VAE-generated images be unclear?}\\[1.5mm]
\textbf{Answer:} VAE-generated images often appear blurry because pixel-wise reconstruction losses (such as MSE) penalize errors globally and encourage the model to output conditional expectation averages when uncertain. Additionally, the KL divergence constraint forces latent distributions to overlap, causing trade-offs between reconstruction sharpness and latent regularity. When generative capacity is constrained or when the decoder attempts to bridge overlapping class boundaries, it averages multi-modal possibilities. This leads to soft, low-pass filtered reconstructions that lack sharp high-frequency edge details.

\vspace{5mm}

\item \textbf{What is the difference between reconstruction and generation?}\\[1.5mm]
\textbf{Answer:} Reconstruction is a conditional mapping process where an existing input image $x$ is encoded into latent space and recreated as $\hat{x} \approx x$. Its goal is to minimize information loss and maximize fidelity relative to a specific source image. In contrast, generation creates entirely novel synthetic data samples from scratch by sampling random latent vectors $z$ from a prior distribution without referencing any specific input image. While reconstruction evaluates encoding-decoding precision, generation tests the model's ability to sample broadly from the learned distribution.

\vspace{5mm}

\item \textbf{Why should test images remain unseen during training?}\\[1.5mm]
\textbf{Answer:} Keeping test images strictly unseen during training is fundamental for evaluating the model's true generalization performance on out-of-sample data. If test images were exposed during training, the network could trivially memorize pixel patterns rather than learning the intrinsic data manifold. Evaluating unseen test data confirms that the autoencoder has captured robust, generalizable representations rather than overfitting to specific training exemplars. It also provides an unbiased assessment of real-world reconstruction capability and anomaly detection reliability.
\end{enumerate}
