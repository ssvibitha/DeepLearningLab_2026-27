\section*{1. Objective}

The objective of this experiment is to develop an end-to-end understanding of
autoencoders and their variants for image representation, reconstruction,
denoising and generative modeling.

The experiment begins with a fully connected autoencoder, progresses to a
Convolutional Autoencoder (CAE), introduces image corruption for denoising,
and finally develops a Variational Autoencoder (VAE). Students will visualize
the learned latent representation, compare reconstruction quality using
quantitative and qualitative measures, and explore the generative capability
of the VAE.

The same image dataset and a controlled experimental protocol should be used
throughout the experiment wherever possible.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section*{2. Learning Outcomes}

After completing this experiment, students will be able to:

\begin{itemize}
\item explain the encoder--latent--decoder structure of an autoencoder;
\item prepare image data for reconstruction-based learning;
\item implement a fully connected autoencoder;
\item implement a Convolutional Autoencoder for image reconstruction;
\item introduce controlled noise and build a denoising autoencoder;
\item evaluate reconstruction using MSE, MAE and SSIM;
\item visualize and interpret latent representations;
\item explain the probabilistic latent representation of a VAE;
\item implement the reparameterization trick;
\item calculate and interpret reconstruction and KL-divergence losses;
\item generate new images by sampling from a learned latent space; and
\item compare deterministic and variational latent representations.
\end{itemize}

\section*{3. Dataset and Experimental Setup}

\textbf{Dataset: MNIST Handwritten Digit Dataset}

MNIST contains grayscale images of handwritten digits from 0 to 9. Each image
has spatial dimensions

\[
28\times28\times1.
\]

The dataset is particularly suitable for this experiment because the images
are small, the classes have visually meaningful structure, and the same image
format can be directly supplied to fully connected, convolutional and
variational autoencoders.

The dataset can be loaded directly using Keras/TensorFlow:

\url{https://www.tensorflow.org/api_docs/python/tf/keras/datasets/mnist}

\textbf{Recommended laboratory subset:}

Use 10,000 training images and 2,000 test images for the main laboratory
execution. The full MNIST dataset may be used if computational resources
permit.

The labels are not required as reconstruction targets. The original image is
the target:

\[
\boxed{x\rightarrow \text{Encoder}\rightarrow z
\rightarrow\text{Decoder}\rightarrow\hat{x}}
\]

where $x$ is the input image and $\hat{x}$ is its reconstruction.

\section*{6. Exploring Autoencoders}

An autoencoder learns to reproduce its input at the output.

The encoder maps the input to a lower-dimensional representation:

\[
z=f_{\theta}(x),
\]

and the decoder reconstructs the input:

\[
\hat{x}=g_{\phi}(z).
\]

The training objective is to minimize reconstruction error:

\[
\mathcal{L}_{rec}
=
\frac{1}{N}\sum_{i=1}^{N}
\|x_i-\hat{x}_i\|^2.
\]

\begin{tikzpicture}[node distance=7mm]

\node[layer,right=of a](b){Encoder};
\node[layer,right=of b](c){Latent\\Vector $z$};
\node[layer,right=of c](d){Decoder};
\node[layer,right=of d](e){Output Image\\$\hat{x}$};

\foreach \x/\y in {a/b,b/c,c/d,d/e}
\draw[arrow](\x)--(\y);
\end{tikzpicture}
\end{center}

The latent vector is a compressed representation of the input.

\section*{15. Variational Autoencoder}

A conventional autoencoder maps an input to a deterministic latent vector:

\[
z=f(x).
\]

A VAE instead learns a probability distribution:

\[
q_{\phi}(z|x)
=
\mathcal{N}
\left(
\mu(x),
\operatorname{diag}(\sigma^2(x))
\right).
\]

The encoder produces:

\[
\mu,\qquad \log\sigma^2.
\]

A latent vector is sampled using the reparameterization trick:

\[
z=\mu+\sigma\odot\epsilon,
\qquad
\epsilon\sim\mathcal{N}(0,I).
\]

\begin{center}
\begin{tikzpicture}[node distance=6mm]
\node[layer](a){Input Image};
\node[layer,right=of a](b){Encoder};
\node[layer,right=of b](c){$\mu,\log\sigma^2$};
\node[layer,right=of c](d){Sampling\\$z=\mu+\sigma\epsilon$};
\node[layer,right=of d](e){Decoder};
\node[layer,right=of e](f){Reconstructed\\Image};

\foreach \x/\y in {a/b,b/c,c/d,d/e,e/f}
\draw[arrow](\x)--(\y);
\end{tikzpicture}
\end{center}

\section*{16. VAE Loss Function}

The VAE objective consists of two components.

\subsection*{Reconstruction Loss}

\[
\mathcal{L}_{rec}
=
-\mathbb{E}_{q_{\phi}(z|x)}
[\log p_{\theta}(x|z)].
\]

For normalized MNIST images, binary cross-entropy can be used.

\subsection*{KL Divergence}

\[
D_{KL}
\left(
q_{\phi}(z|x)\parallel p(z)
\right)
=
-\frac{1}{2}
\sum_j
\left(
1+\log\sigma_j^2-\mu_j^2-\sigma_j^2
\right).
\]

The total loss is

\[
\boxed{
\mathcal{L}_{VAE}
=
\mathcal{L}_{rec}
+
\mathcal{L}_{KL}
}
\]

where the prior is usually

\[
p(z)=\mathcal{N}(0,I).
\]

\subsection*{Plot 1: Original versus Reconstructed Images (Basic FC Autoencoder)}

\begin{figure}[H]
\centering
\includegraphics[width=0.88\linewidth]{Images/fc_ae_reconstruction.png}
\caption{Reconstruction results of the Fully Connected Autoencoder ($d_z = 16$). Top row: Original MNIST test digits. Bottom row: Corresponding decoded reconstructions $\hat{x}$.}
\end{figure}

\textbf{Inference:} The plot compares original MNIST test digits with reconstructions from the Fully Connected Autoencoder ($d_z = 16$). The reconstructed outputs correctly capture digit class identity and orientation, but exhibit visible blurring and softened stroke edges, reflected in a moderate $\text{SSIM} = 0.728950$ and $\text{MSE} = 0.022779$. Flattening 2D images to 1D discards spatial locality, forcing fully connected layers to learn pixel correlations globally, which promotes low-pass smoothing under MSE loss. This confirms that while a fully connected AE learns meaningful compressed representations, it lacks the spatial inductive bias needed for sharp, high-fidelity reconstruction.

\begin{figure}[H]

\textbf{Inference:} The plot shows training and validation Binary Cross-Entropy loss over 20 epochs for the Fully Connected Autoencoder. Both curves drop steeply in the first 4 epochs then gradually plateau near $0.095$, with training and validation loss remaining tightly coupled throughout, indicating no overfitting. The bottleneck dimension ($d_z = 16$) acts as an implicit regularizer, preventing the $211,040$ parameters from memorizing individual samples. The smooth convergence confirms that the Adam optimizer and the chosen architecture are well-suited for stable reconstruction learning on the MNIST subset.

\begin{enumerate}
\item \textbf{Effect of Latent Dimension on Reconstruction:}
Increasing the latent bottleneck capacity ($d_z \in \{2, 8, 16, 32\}$) monotonically improves reconstruction quality (MSE drops from $0.046838$ to $0.018799$; SSIM rises from $0.434463$ to $0.771977$). A severe bottleneck forces excessive loss of high-frequency stroke details, while larger latent vectors preserve sharper geometric edges at the expense of compression efficiency.

Convolutional autoencoders significantly outperform fully connected autoencoders in visual fidelity (CAE achieves $\text{SSIM} = 0.973643$ vs. $\text{SSIM} = 0.728950$ for FC-AE; MSE is nearly $10\times$ lower) while utilizing $64.7\%$ fewer parameters ($74,497$ vs. $211,040$). Preserving 2D spatial locality and translation equivariance avoids the severe edge blurring caused by 1D vector flattening.

\item \textbf{Effect of Gaussian Noise Level:}
Reconstruction degradation scales non-linearly with input noise standard deviation ($\sigma \in \{0.1, 0.2, 0.3\}$). While the network demonstrates strong resilience at $\sigma \le 0.2$ ($\text{SSIM} \ge 0.94$), severe corruption at $\sigma = 0.3$ causes SSIM to drop to $0.872354$ as noise artifacts begin to mask digit stroke boundaries.

\item \textbf{Ability of Denoising AE to Recover Image Structure:}
By learning an orthogonal projection from the corrupted off-manifold space back onto the clean data manifold, the Denoising CAE suppresses background noise and reconnects fragmented strokes, achieving clean reconstructions ($\text{MSE} = 0.004679$, $\text{SSIM} = 0.944660$).

\item \textbf{Characteristics of the VAE Latent Distribution:}
Regularized by the Kullback-Leibler divergence $D_{KL}(q_\phi(z|x) \parallel \mathcal{N}(0, I))$, the VAE latent distribution is smooth, continuous, and centered at the origin without isolated clusters or unbounded voids.

\item \textbf{Structure of the 2D VAE Latent Space:}
Digits form distinct semantic clusters in the 2D plane ($z_1, z_2$) in an unsupervised manner. Morphologically similar digits (e.g., 3, 5, 8) lie adjacent with gentle boundary transitions, enabling smooth class morphing.

\item \textbf{Quality and Diversity of Generated Samples:}
Sampling random latent coordinates from the prior $z \sim \mathcal{N}(0, I)$ produces diverse, structurally plausible synthetic handwritten digits spanning multiple classes, validating that the decoder maps prior density to the true data manifold.

\item \textbf{Smoothness of Latent-Space Interpolation:}
Linear interpolation along geodesics $z(\alpha) = (1-\alpha)z_A + \alpha z_B$ yields seamless continuous morphing without artifacts, proving the absence of ``holes'' in the learned manifold.

\item \textbf{Relationship between Reconstruction Error and Visual Quality:}
Lower MSE and higher SSIM correlate directly with crisp edge boundaries, high contrast, and absence of visual blur. SSIM serves as a more perceptually consistent metric than MSE for evaluating stroke structure.

\item \textbf{Differences between Deterministic and Probabilistic Latent Representations:}
Deterministic autoencoders map inputs to fixed point vectors, yielding sharp reconstructions but fractured latent spaces unsuited for generation. VAEs learn continuous probability density distributions $(\mu, \sigma^2)$, trading off marginal reconstruction sharpness for principled generative sampling and interpolation.
\end{enumerate}

\section*{28. Discussion Questions}

\begin{enumerate}
\item \textbf{What is an autoencoder?}\\[1.5mm]
\textbf{Answer:} An autoencoder is an unsupervised neural network. It consists of encoder, bottleneck and decoder . The encoder compresses the input into a latent bottleneck and a decoder  reconstructs the input. The network is trained by minimizing reconstruction error between the original input and reconstructed output. The bottleneck makes sure the network learns dominant hidden patterns rather than memorizing individual samples.

\vspace{5mm}

\item \textbf{What is the purpose of the encoder?}\\[1.5mm]
\textbf{Answer:} The encoder acts as a dimensionality reduction and feature extraction function. It maps high dimensional raw input data into a compact latent vector space. It progressively discards redundant information, noise, and irrelevant variations while preserving essential semantic features. This compressed code captures the most important features of the data needed to reconstruct the original input accurately.

\vspace{5mm}

\item \textbf{What is the purpose of the decoder?}\\[1.5mm]
\textbf{Answer:} The decoder is a generative reconstruction network. The primary task of a decoder is to reconstruct the original input in a high-dimensional space from the low-dimensional latent code obtained from the encoder. It synthesizes an approximation of the input using learned structural priors by inverting the bottleneck compression. The decoder ensures that the latent space contains enough information fidelity to reconstruct identifiable high quality images.

\vspace{5mm}

\item \textbf{What is a latent representation?}\\[1.5mm]
\textbf{Answer:} The decoder is a generative reconstruction network. The primary task of a decoder is to reconstruct the original input in a high-dimensional space from the low-dimensional latent code obtained from the encoder. It synthesizes an approximation of the input using learned structural priors by inverting the bottleneck compression. The decoder ensures that the latent space contains enough information fidelity to reconstruct identifiable high quality images.

\vspace{5mm}

\item \textbf{Why is the latent representation usually smaller than the input?}\\[1.5mm]
\textbf{Answer:} If the latent dimension is less than the input, there arises an information bottleneck, forcing the network to retain only important aspects of the input data and not allowing it to memorize the input data.
 Thus, it is possible to reconstruct the original input using just the important information and discarding all the noise.

\vspace{5mm}

\item \textbf{What happens when the latent dimension is too small?}\\[1.5mm]
\textbf{Answer:} In case the latent dimension is too constrained (for highly dimensional data), an information bottleneck happens. There is no enough expressive power of the network to capture fine structure and high frequency details. The reconstruction error (MSE) is very high, the fine stroke boundaries are lost and there is high blurriness of the reconstructed images. In addition, different classes/ features might be overlapped or even collapsed in latent space.

\vspace{5mm}

\item \textbf{What happens when the latent dimension is increased?}\\[1.5mm]
\textbf{Answer:} A larger latent dimension means that there is more capacity for information storage within the neural network, making it possible to extract detailed information such as edges and textures. This tends to improve the quality of reconstructed images and lowers the error. However, an excessively large latent dimension will only make the network copy the input image rather than extracting features. This reduces the effectiveness of data compression.

\vspace{5mm}

\item \textbf{Why can a convolutional autoencoder preserve spatial information more effectively?}\\[1.5mm]
\textbf{Answer:} Convolutional Autoencoders (CAEs) retain spatial structure due to their use of local receptive fields, weight sharing, and 2-dimensional activation maps instead of flattening the image into a 1D vector. The flattening of an image in a fully connected neural network causes the loss of the 2-dimensional geometric structure, spatially adjacent nature, and local dependencies between the pixels. CAEs have built-in translation equivariance that enables them to identify local visual elements (edges, curves, loops) irrespective of their location.

\vspace{5mm}

\item \textbf{Differentiate an autoencoder and a denoising autoencoder.}\\[1.5mm]
\textbf{Answer:} While a regular autoencoder takes the input vector \(x\) and attempts to reproduce the same input vector after putting it through the bottleneck process, a denoising autoencoder (DAE) takes the corrupted input vector \(\tilde{x} = x + \eta\) as the input while considering the original input vector \(x\) as the target. Hence, the denoising autoencoder will train itself to ignore any kind of noise in the training data and learn the features of interest in the training data.
\vspace{5mm}

\item \textbf{Why is the clean image used as the target in denoising?}\\[1.5mm]
\textbf{Answer:} As the clean image serves as the target, the learning process ensures that the network captures the manifold of the noiseless data points instead of trying to reconstruct the noise itself. Thus, the optimization function discourages the presence of any noise in the reconstructed image, encouraging the network to identify the invariant features of the underlying manifold. It results in the learning of an orthogonal projection of the noisy ambient space onto the manifold of dense data points.

\vspace{5mm}

\item \textbf{What happens when the noise level is increased?}\\[1.5mm]
\textbf{Answer:} When the variance or standard deviation of input noise ($\sigma$) increases, the noisy points move farther away from the clean data manifold. In moderate amounts of noise, the autoencoder is resilient and can filter out noise successfully, although there is some loss in edge sharpness. But when there is too much noise, the important structural elements get covered up. Therefore, there is a rapid drop in the value of SSIM, an increase in MSE, and blurring in the reconstructed image.

\vspace{5mm}

\item \textbf{Why are MSE, MAE and SSIM useful for image reconstruction?}\\[1.5mm]
\textbf{Answer:}  MSE and MAE give pixel‑by‑pixel numbers that show how much the rebuilt image differs from the original. MSE gives penalties for large mistakes. Yet pixel‑by‑pixel numbers do not always show how a human sees the picture and they can make a blurry picture look good. SSIM fixes this problem, by checking how light, contrast and structure have changed between pixels. Using MSE, MAE and SSIM together gives a test of both the numbers and the way the image looks to people.

\vspace{5mm}

\item \textbf{What is a Variational Autoencoder?}\\[1.5mm]
\textbf{Answer:} A Variational Autoencoder (VAE) is a directed generative model that blends deep neural networks with variational Bayesian inference. In a Variational Autoencoder the encoder does not send an input to a point; it sends the input to the parameters of a probability distribution: a mean $ \mu $ and a log-variance $ \log\sigma^2 $. The decoder then takes a sample from this distribution. Uses it to rebuild the input. By training, with an objective that balances how well the input is rebuilt and how tightly the latent codes are kept in check a Variational Autoencoder guarantees that the latent space remains smooth and continuous making it easy to generate samples.

\vspace{5mm}

\item \textbf{How does a VAE differ from a conventional autoencoder?}\\[1.5mm]
\textbf{Answer:} A conventional autoencoder maps each input image to a point in latent space. This deterministic mapping often creates gaps, breaks and overfitting. By contrast a VAE maps inputs to smooth probability density functions. The VAE uses Kullback‑Leibler (KL) divergence to keep the latent space close, to a normal prior. This rule makes the latent space smooth, full and free of holes. While a conventional autoencoder can only reconstruct and compress a VAE can also create believable images by sampling from the prior distribution.

\vspace{5mm}

\item \textbf{Why does a VAE learn a distribution instead of a single latent vector?}\\[1.5mm]
\textbf{Answer:} The learning of distributions creates noise and smoothes out some parts of the space. This way, the encoder does not only remember but also places the input data into sensible places. When the inputs are mapped into the regions by mu and sigmoid portions of the hidden space, the outcomes come out to be quite alike. The outputs become unreasonable because of this way. The distribution technique enables us to generate data based on our knowledge of mathematics.

\vspace{5mm}

\item \textbf{What is the reparameterization trick?}\\[1.5mm]
The reparameterization trick is a way to recast the algorithm such that the gradients can be passed backwards through random sampling nodes in a neural network model. Direct random sampling $z \sim \mathcal{N}(\mu, \sigma^2)$ cannot be differentiated due to the fact that the random variables do not have continuous gradients with respect to the parameters of the model. Instead, the trick separates the randomness by drawing a random noise vector $\epsilon \sim \mathcal{N}(0, I)$ and calculating $z = \mu + \sigma \odot \epsilon$ deterministically.

\vspace{5mm}

\item \textbf{Why is $\epsilon$ sampled from a standard normal distribution?}\\[1.5mm]
\textbf{Answer:} $\epsilon$ drawn from the standard Gaussian distribution $\mathcal{N}(0, I)$ yields a stochastic source of parameters with mean 0 and variance 1 that is entirely independent of the weights of the model. This independence guarantees that the random number generator does not contribute to the backpropagation of gradients. In addition, scaling and shifting a standard Gaussian by $\sigma$ and $\mu$ respectively results in a Gaussian distribution $\mathcal{N}(\mu, \sigma^2)$, which is precisely what is desired.

\vspace{5mm}

\item \textbf{What is the role of KL divergence in the VAE loss?}\\[1.5mm]
\textbf{Answer:} The Kullback-Leibler (KL) divergence is a kind of statistical regularizer for how much the posterior $q_\phi(z|x)$ produced by the encoder deviates from the prior $p(z)=\mathcal{N}(0, I)$. In other words, it penalizes the cases where the distributions have the means not close to zero and variance not equal to one. This way, the model won't have separated regions of different classes in the latent space. The latent space will be smooth, centered, and densely occupied.

\vspace{5mm}

\item \textbf{What is the prior distribution used in the VAE?}\\[1.5mm]
\textbf{Answer:} The usual prior used for VAE is that of an isotropic multivariate Gaussian having the probability density function of $p(z) = \mathcal{N}(0, I)$. This particular prior defines the latent variables to be zero-mean, independent of each other, and unit-variance in all dimensions. This prior provides a simple and analytical prior for determining the closed-form KL-divergence for posterior Gaussians. In addition, the normality of the prior in standard form helps in sample generation.

\vspace{5mm}

\item \textbf{Why is a two-dimensional latent space useful for visualization?}\\[1.5mm]
\textbf{Answer:} A two-dimensional latent space ($d_z = 2$) allows for simple visualization of the latent coordinate system by plotting the latent coordinates on a two-dimensional plane without further dimensionality reduction steps such as PCA or t-SNE. This not only facilitates the interpretation of class separability and manifold structure, but also provides an intuitive means to analyze variations of digit shapes across the latent space by exploring it on a two-dimensional grid. In short, a two-dimensional latent space is an easy-to-interpret probe into the representational geometry of the latent space.

\vspace{5mm}

\item \textbf{What does latent-space interpolation demonstrate?}\\[1.5mm]
\textbf{Answer:} The latent-space interpolation works by exploring an arbitrary continuous trajectory (e.g., a straight line $z(\alpha) = (1-\alpha)z_A + \alpha z_B$) in the latent space and decoding the obtained latent vectors as images. This procedure qualitatively confirms that the latent space is continuous, compact, and ordered in a semantically meaningful way. In particular, if the decoded images change in a non-garbled way from one digit class to another, this implies that the latent manifold does not possess holes or gaps. This is a critical property that facilitates decoder learning of the true underlying data distribution.

\vspace{5mm}

\item \textbf{Why can a VAE generate new images?}\\[1.5mm]
\textbf{Answer:} A VAE is able to generate novel images because it's training objective regularizes the encoder distribution to be close to a known, tractable prior $p(z) = \mathcal{N}(0, I)$.
Because the latent space is continuous and dense, almost every latent vector drawn from this distribution will correspond to a valid point on the data manifold. To synthesize a novel image, one just draws a random sample $z \sim \mathcal{N}(0, I)$ and passes it through the trained decoder, which will reconstruct a realistic synthetic image with the characteristic features of the training domain.

\vspace{5mm}

\item \textbf{Why might some VAE-generated images be unclear?}\\[1.5mm]
\textbf{Answer:}The images generated by VAE tend to be blurry because the pixel-wise reconstruction loss (e.g., MSE) penalizes the network for global errors and encourages it to learn the conditional expectation of the distribution. Furthermore, the KL divergence term in the loss function forces the distributions in the latent space to overlap, resulting in a trade-off between reconstruction quality and latent space regularity. Generative capacity being constrained or the decoder trying to interpolate between different modes in the latent space results in the learned model outputting a blurred version of any multi-modal distribution in the training set.

\vspace{5mm}

\item \textbf{What is the difference between reconstruction and generation?}\\[1.5mm]
\textbf{Answer:} Reconstruction is a process where an existing input image x is turned into a latent space representation and then rebuilt as x equal to x. The purpose is to make sure that there is little information lost and that the result is very close to the original image. On the hand generation is when completely new data is created from nothing by taking random latent vectors z from a certain distribution and not looking at any specific input image. While reconstruction checks how well the model can encode and decode generation checks how well the model can create samples, from the distribution it has learned.

\vspace{5mm}

\item \textbf{Why should test images remain unseen during training?}\\[1.5mm]
\textbf{Answer:} I think that keeping test images hidden during training is essential for determining how the model will perform on new data. If test images were visible to the model during training the model could remember pixel patterns of learning the real shape of the data. Testing the model on test images shows that the autoencoder has learned good general representations instead of just copying specific training examples. It also gives a view of how well the model can reconstruct images in the real world and how reliable it is, at detecting unusual pictures.

\end{enumerate}
