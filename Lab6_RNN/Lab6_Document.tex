\section{Objective}

The objective of this experiment is to develop an end-to-end understanding of
recurrent sequence learning by implementing and comparing Vanilla RNN, LSTM
and GRU models. The experiment also introduces Backpropagation Through Time
(BPTT), the limitations of conventional RNNs, and the use of CNN-extracted
features with recurrent networks for video understanding.

The experiment uses the UCI Human Activity Recognition Using Smartphones
dataset as the primary sequence dataset. Students will prepare temporal input
sequences, visualize them, train RNN/LSTM/GRU models, compare their
performance, analyze convergence and generalization, and extend the pipeline
to video understanding using CNN feature extraction followed by an LSTM or
GRU.

A small synthetic sequence-to-sequence task is included at the end to
demonstrate the encoder--decoder framework.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Learning Outcomes}

After completing this experiment, students will be able to:

\begin{itemize}
\item represent sequential data using the $(N,T,F)$ input format;
\item explain the architecture and operation of a Vanilla RNN;
\item explain Backpropagation Through Time and the vanishing/exploding gradient challenges;
\item implement sequence classification using SimpleRNN, LSTM and GRU;
\item compare RNN, LSTM and GRU using quantitative performance measures;
\item interpret training/validation curves and confusion matrices;
\item explain the role of CNNs in extracting spatial features from video frames;
\item construct a CNN--LSTM or CNN--GRU pipeline for video understanding;
\item explain the encoder--decoder architecture for sequence-to-sequence learning; and
\item draw conclusions using predictive performance, model complexity and computational cost.
\end{itemize}

\section{Vanilla RNN Architecture}

A Vanilla RNN maintains a hidden state that is updated at every time step:

\[
h_t=\tanh(W_xx_t+W_hh_{t-1}+b_h).
\]

The output can be written as

\[
y_t=g(W_yh_t+b_y).
\]

For sequence classification, the final hidden representation can be passed
to a classifier.

\begin{center}
\begin{tikzpicture}[node distance=7mm]
\node[layer](x1){$x_1$};
\node[layer,right=of x1](h1){$h_1$};
\node[layer,right=of h1](x2){$x_2$};
\node[layer,right=of x2](h2){$h_2$};
\node[layer,right=of h2](x3){$\cdots$};
\node[layer,right=of x3](h3){$h_T$};
\node[layer,right=of h3](y){Softmax};

\draw[arrow](x1)--(h1);
\draw[arrow](h1)--(x2);
\draw[arrow](x2)--(h2);
\draw[arrow](h2)--(x3);
\draw[arrow](x3)--(h3);
\draw[arrow](h3)--(y);
\end{tikzpicture}
\end{center}

The diagram represents the unrolled view of an RNN. The same recurrent weights
are reused across time steps.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Backpropagation Through Time}

When an RNN is unrolled, the loss depends on the sequence of hidden states.
Backpropagation Through Time (BPTT) propagates the error backward through
the recurrent steps.

\begin{center}
\begin{tikzpicture}[node distance=5mm]
\node[smalllayer](a){$h_1$};
\node[smalllayer,right=of a](b){$h_2$};
\node[smalllayer,right=of b](c){$h_3$};
\node[smalllayer,right=of c](d){$\cdots$};
\node[smalllayer,right=of d](e){$h_T$};
\node[smalllayer,below=of e](l){Loss};

\draw[arrow](a)--(b);
\draw[arrow](b)--(c);
\draw[arrow](c)--(d);
\draw[arrow](d)--(e);
\draw[arrow](e)--(l);

\draw[arrow]($(e.south)!0.5!(l.north)$) to[bend right=35]
node[below,font=\scriptsize]{backward gradient} ($(a.south)!0.5!(b.south)$);
\end{tikzpicture}
\end{center}

Students should explain that repeated multiplication of derivatives through
many time steps can cause gradients to become extremely small or extremely
large.

\subsection{Challenges}

\begin{itemize}
\item Vanishing gradients
\item Exploding gradients
\item Difficulty learning long-term dependencies
\item Sequential computation and limited parallelism
\end{itemize}

The vanishing-gradient problem can be conceptually represented as

\[
\left|\frac{\partial h_t}{\partial h_{t-k}}\right|\rightarrow0
\]

while exploding gradients correspond to very large gradient magnitudes.

\subsection{Numerical Exercise}

Consider

\[
x_1=0.5,\qquad x_2=0.7,\qquad x_3=0.2,
\]

\[
h_0=0,\qquad W_x=0.5,\qquad W_h=0.8,\qquad b=0.1.
\]

Using

\[
h_t=\tanh(W_xx_t+W_hh_{t-1}+b),
\]

calculate $h_1$, $h_2$ and $h_3$ manually.

Students must compare their calculated values with the values obtained from
a program.

\section{LSTM Architecture}

LSTM introduces a memory cell and gates to control information flow.

The forget gate is

\[
f_t=\sigma(W_f[h_{t-1},x_t]+b_f),
\]

the input gate is

\[
i_t=\sigma(W_i[h_{t-1},x_t]+b_i),
\]

and the output gate is

\[
o_t=\sigma(W_o[h_{t-1},x_t]+b_o).
\]

The candidate cell state is

\[
\tilde{C}_t=
\tanh(W_C[h_{t-1},x_t]+b_C),
\]

and the cell state is

\[
C_t=f_tC_{t-1}+i_t\tilde{C}_t.
\]

The hidden state is

\[
h_t=o_t\tanh(C_t).
\]

\begin{tikzpicture}[node distance=5mm]
\node[layer](a){Input\\$x_t$};
\node[layer,right=of a](b){LSTM\\Cell};
\node[layer,right=of b](c){$h_t$};
\node[layer,above=of b](d){$C_t$};
\node[layer,right=of c](e){Classifier};

\draw[arrow](a)--(b);
\draw[arrow](b)--(c);
\draw[arrow](b)--(d);
\draw[arrow](c)--(e);
\draw[arrow](d)--(b);
\end{tikzpicture}
\end{center}

\section{GRU Architecture}

GRU uses two principal gates:

\[
z_t=\sigma(W_z[h_{t-1},x_t]+b_z)
\]

and

\[
r_t=\sigma(W_r[h_{t-1},x_t]+b_r).
\]

The candidate hidden state is

\[
\tilde{h}_t=
\tanh(W_h[r_t\odot h_{t-1},x_t]+b_h).
\]

The hidden state is updated using

\[
h_t=(1-z_t)h_{t-1}+z_t\tilde{h}_t.
\]

\frac{\text{Correctly predicted tokens}}
{\text{Total tokens}}.
\]

Sequence accuracy is

\[
\text{Sequence Accuracy}
=
\frac{\text{Completely correct sequences}}
{\text{Total sequences}}.
\]

\section{Discussion Questions}

\begin{enumerate}

\item \textbf{What is a recurrent neural network?}\\
\textit{Answer:} A recurrent neural network (RNN) is a class of neural network designed for sequential data. Unlike feed-forward networks, an RNN maintains a hidden state $h_t$ that is updated at each time step using both the current input $x_t$ and the previous hidden state $h_{t-1}$. This enables the network to model temporal dependencies.\\
\vspace{8mm} 

\item \textbf{What information is represented by the hidden state?}\\
\textit{Answer:} The hidden state consists of a compressed learned summary of all inputs seen up to the current time step. It encodes context from past inputs and is used to inform predictions at the current and future time steps.\\
\vspace{8mm}

\item \textbf{Why is sequence order important?}\\
\textit{Answer:} The temporal ordering of samples encodes causal and dynamic relationships. In activity recognition, a footstep contributes to a specific kinematic phase. Shuffling the time order destroys this structure and eliminates the temporal patterns that distinguish one activity from another.\\
\vspace{8mm}

\item \textbf{Explain the difference between a feed-forward network and an RNN.}\\
\textit{Answer:} A feed-forward network maps an input to an output without memory of previous inputs. Here, every sample is processed independently. An RNN processes inputs one time step at a time while carrying a hidden state forward. This allows information from earlier time steps to influence later computations.\\
\vspace{8mm}

\item \textbf{Explain Backpropagation Through Time.}\\
\textit{Answer:} Backpropagation Through Time unrolls the RNN across all $T$ time steps to form a computational graph which is equivalent to a deep feed-forward network with shared weights. The standard chain rule is applied through this unrolled graph to compute gradients with respect to the recurrent weights. These weights are then updated by the optimizer.\\
\vspace{8mm}

\item \textbf{Why can gradients vanish during BPTT?}\\
\textit{Answer:} When the magnitude of the recurrent weight matrix (or) its derivative after the activation is less than one, the repeated multiplication across many time steps drives gradients exponentially towards zero. This prevents the network from learning long-range dependencies and results in vanishing gradient problem.\\
\vspace{8mm}

\item \textbf{Why can gradients explode during BPTT?}\\
\textit{Answer:} When the recurrent weight matrix has values greater than one, the repeated multiplication exponentially increases the value of gradients . This causes unstable training and results in exploding gradient problem. This is commonly addressed with gradient clipping.\\
\vspace{8mm}

\item \textbf{What are long-term dependencies?}\\
\textit{Answer:} Long-term dependencies are relationships between information that occurs far apart in a sequence. For example, a word at the beginning of a sentence may be needed to understand a word near the end. Vanilla RNNs have difficulty remembering such information because of the vanishing gradient problem.\\\vspace{8mm}

\item \textbf{What is the role of the LSTM cell state?}\\
\textit{Answer:} The cell state acts as a long-term memory highway that runs across time steps with only multiplicative gate interactions. This minimises information loss. These gates selectively add relevant information or remove irrelevant information from the cell state.\\
\vspace{8mm}

\item \textbf{What are the forget, input and output gates in LSTM?}\\
\textit{Answer:} The forget gate determines what fraction of the previous cell state to retain. The input gate determines how much of the new candidate cell state to write into memory. The output gate determines how much of the current cell state to expose as the hidden state.\\
\vspace{8mm}

\item \textbf{What are the reset and update gates in GRU?}\\
\textit{Answer:} The reset gate controls how much of the previous hidden state is used when computing the candidate state. This allows the model to forget irrelevant history. The update gate operates between the previous hidden state and the candidate state, deciding how much the hidden state should change at each step.\\
\vspace{8mm}

\item \textbf{Compare LSTM and GRU.}\\
\textit{Answer:} LSTM uses three gates and maintains separate hidden and cell states which gives it greater expressive capacity but higher parameter count. GRU uses two gates and merges the hidden and cell states into a single hidden state, resulting in fewer parameters and faster training. In practice, GRU achieves accuracy comparable to LSTM on many sequence tasks.\\
\vspace{8mm}

\item \textbf{Why does GRU generally use a simpler gating mechanism than LSTM?}\\
\textit{Answer:} GRU was designed to achieve the main advantage of LSTM ie. mitigating vanishing gradients. GRU achieves this with reduced architectural complexity. The update gate combines the roles of both the forget and input gates by coupling the forget and input decisions and there is no separate cell state which reduces the number of weight matrices and computation.\\
\vspace{8mm}

\item \textbf{Why should RNN, LSTM and GRU be compared using the same experimental settings?}\\
\textit{*Answer:*} Controlled comparison requires that all factors except the recurrent architecture (dataset, preprocessing, split, optimizer, learning rate, batch size, hidden units, and epochs) are kept constant. This ensures that both models are trained and evaluated under the same conditions. Otherwise, a difference in performance may be caused by factors such as a different learning rate or number of epochs, rather than the architecture itself. Therefore, keeping these factors constant allows us to fairly measure the effect of the recurrent architecture.\\
\vspace{8mm}

\item \textbf{What does the confusion matrix reveal that accuracy alone does not?}\\
\textit{Answer:} The confusion matrix reveals class-level performance, showing which specific activities are correctly identified and which are confused with each other. Accuracy aggregates all predictions into a single number and can be misleading when class distributions are imbalanced.\\
\vspace{8mm}

\item \textbf{Why should macro F1-score be reported for multi-class classification?}\\
\textit{Answer:} Macro F1 computes the F1-score independently for each class and averages them, giving equal weight to each class regardless of sample count. This prevents the overall metric from being dominated by the majority class, which is important when class sizes are unequal.\\
\vspace{8mm}

\item \textbf{What is the significance of sequence length?}\\
\textit{Answer:} Longer sequences provide more temporal context which can potentially improve accuracy, but at the same time increases computation and the risk of vanishing gradients. Shorter sequences reduce computational cost but may truncate important temporal patterns. This leads to lower performance.\\
\vspace{8mm}

\item \textbf{Why can a CNN be used as a feature extractor for video?}\\
\textit{Answer:} A CNN learns to detect spatially local patterns such as edges, textures, object parts in image data. When applied to individual video frames, it transforms each 2-D image into a compact feature vector encoding spatial content. These features can then be arranged as a temporal sequence for an RNN or LSTM or GRU model.\\
\vspace{8mm}

\item \textbf{What type of information is extracted by the CNN?}\\
\textit{Answer:} The CNN extracts spatial features from each frame which includes low-level features such as edges and colours in early layers and high-level semantic features such as human body posture, object identity and scene context in deeper layers.\\
\vspace{8mm}

\item \textbf{What type of information is learned by the recurrent network?}\\
\textit{Answer:} The recurrent network learns temporal dynamics which tells us how the CNN feature vectors change across frames, capturing motion patterns, speed, direction of movement and the temporal order of events that collectively identify an action.\\
\vspace{8mm}

\item \textbf{Why are CNN features arranged as a sequence before being given to LSTM/GRU?}\\
\textit{Answer:} A video is inherently sequential where actions unfold over time. Arranging frame features as an ordered sequence preserves temporal order which enables models like LSTM/GRU to model how appearance changes over time which is essential for distinguishing dynamic actions from static ones.\\
\vspace{8mm}

\item \textbf{Explain the encoder and decoder in sequence-to-sequence learning.}\\
\textit{Answer:} The encoder processes the entire input sequence and compresses it into a context vector. The decoder receives the context vector as its initial state and generates the output sequence one token at a time, conditioning each output on both the context and the previously generated token.\\
\vspace{8mm}

\item \textbf{What is teacher forcing?}\\
\textit{Answer:} Teacher forcing is a training strategy for seq2seq models where the ground-truth output token from the previous time step is fed as input to the decoder at the current step, rather than the decoder's own previous prediction. This stabilises training but can introduce a discrepancy between training and inference behaviour.\\
\vspace{8mm}

\item \textbf{Differentiate token accuracy and sequence accuracy.}\\
\textit{Answer:} Token accuracy counts the fraction of individual output tokens that are predicted correctly, regardless of whether the full sequence matches. Sequence accuracy counts only those sequences where every single token is correct. Sequence accuracy is less than or equal to token accuracy because one wrong token invalidates the entire sequence.\\
\vspace{8mm}

\item \textbf{Why must the test set remain untouched during model selection?}\\
\textit{Answer} The test set must remain untouched because it is used to give an unbiased estimate of how the final model performs on unseen data. If it is used for model selection or tuning, the model may indirectly adapt to the test data which leads the model to achieve high testing accuracy. This makes the model unreliable to adapt to actual real world datasets.\\
\vspace{8mm}

\end{enumerate}
